# 冒險者 ADVENTURE（暫定名稱）

像素風的放置養成 RPG 原型：平日掛機養成，假日挑戰神之試煉、親手搭配祝福。

## 開始開發

需要 Node.js 20 以上。

```bash
npm install
```

```bash
npm run dev
```

開啟終端機顯示的網址就能玩。其他指令：

- `npm run build`：打包到 `dist/`，整個資料夾放到任何網頁空間都能開。
- `npm run preview`：在本機預覽打包結果。
- `npm test`：執行遊戲規則的測試。
- 開發時打開 `/tools/sprites.html`：一次看男女角色、各種裝備外觀、稀有度、材料階級的裝備像素圖，以及所有背包圖示。
- 開發時打開 `/tools/hairstyles.html`：早期的髮型挑選頁（舊的手繪 Q 版，遊戲已不使用）。
- 開發時打開 `/tools/rig.html`：骨架動畫預覽（`src/rig/`）。可切換正面與側面、性別、髮色、服裝、稀有度、材料階級，播放待機、走路、四種武器的三段連招、受擊。
- 開發時打開 `/tools/model3d.html`：3D 像素風人物設計稿（Three.js，`src/three/`）。已放棄這個方向，留作紀錄，遊戲沒有使用。

第一次進遊戲會先建立角色（性別與髮色），之後可以在角色面板按「更換外觀」修改。進度存在瀏覽器裡。「設定」裡的「快轉 1 小時」「取得全部裝備」「刪除全部裝備」是測試用的，可以馬上看到離線收穫、試穿每一款裝備。

## 怎麼玩

- **掛機地點**：鍛鍊室、戰鬥地圖、鍛造室、市集，同時只能選一處。每 5 秒結算一次，關掉網頁也會繼續（最多 12 小時）。
- **戰鬥地圖**：五張地圖，每張分三段、每段 10 級、掉一個階級的素材：綠風草原 Lv1–30（T1–T3），幽暗森林、鐵鏽礦坑 Lv11–40（T2–T4），亡者墓穴、熔岩火山 Lv21–50（T3–T5）。魔物的等級跟著主角，但不超出那一段。每段的段尾有一個頭目（共 15 隻），打倒才能去下一段；還沒打倒的頭目隨時可以挑戰，打倒過的要用狩獵券重打（每小時恢復一張，最多 3 張），首次擊敗金幣 ×3。資料在 `data.js` 的 `AREAS`、`stageOf`，頭目的強度在 `BOSS`。
- **素材**：每種魔物掉自己的素材（史萊姆黏液、狼皮、硬甲殼…共 15 種），階級看在哪一段打到的；每個頭目也掉專屬素材（甲蟲女王的女王甲殼…共 15 種）。魔物和頭目都不掉裝備，裝備只能鍛造。
- **鍛造**：每一款裝備有自己的配方（`gear.js` 的 `cost`），寫的是要哪幾類素材各幾個：硬材、皮料、靈材（`MAT_CATS`），同一類、同一階的素材可以互相代替。全部用同一階的素材，用哪一階就做出哪一階的裝備；可以指定部位、款式和素材階級。勾選「加入頭目素材」時每件多用一個同階的頭目素材，稀有度抽兩次取好的。每一隻頭目都有一套頭目套裝，配方要用那隻頭目的素材（例如炎龍套裝要炎龍鱗）；用頭目素材的款式要在鍛造室指定款式才做得出來。
- **裝備與職業**：職業由武器決定：劍是劍士、弓是弓手（連鎖），鎚是守衛（反擊），法杖是術士（燃燒）；防具和飾品不影響職業，飾品專門出詞條。裝備不限階級，誰都能穿。史詩、傳說裝備有會改變戰鬥行為的特殊效果。角色外觀會隨裝備改變。
- **冒險者階級**：新手、初級、中級、高級、資深、傳奇冒險者，看冒險者聲望（完成公會的每日委託會增加），在 `data.js` 的 `RANKS`。冒險者階級決定能刷到哪一階的素材：T1 新手、T2 初級、T3 中級、T4 高級、T5 資深。每張地圖的第二、三段要先打倒前一段的頭目；草原以外的地圖，第一段要先在任何一張地圖打倒前一個等級的頭目（例如森林、礦坑從 11 級開始，要先打倒一隻 Lv10 的頭目）。
- **公會**：不能掛機。每天當地時間 00:00 刷新 3 個委託：在指定地圖擊敗指定的魔物（接到委託之後才開始算），或交付指定數量的某種素材（交付後扣掉；市集會先留著這些素材）。委託多半出在目前能去的最高階的段。完成後到公會領取金幣與冒險者聲望，每個委託一天只能完成一次。數量與獎勵在 `data.js` 的 `GUILD`。
- **神之試煉**：每週一重置，每過 3 關從三個祝福中選一個（一般、稀世、史詩、神之四級）。

## 架構

分成三層，彼此只透過明確的介面溝通：

| 資料夾 | 負責 | 用到 |
| --- | --- | --- |
| `src/core/` | 遊戲規則：數值、戰鬥、掛機結算、鍛造、試煉、存檔。純運算，不碰畫面 | 無 |
| `src/ui/` | 文字多的畫面：HUD、角色數值、掛機地點、背包、公會委託、祝福選擇 | HTML / CSS |
| `src/game/` | 戰鬥畫面：戰鬥地圖的掛機場景、戰鬥播放、傷害數字、裝備閃光 | Phaser 4 |

- 版面以手機直式為主（單欄，桌機上置中）：最上面是狀態列；接著是戰鬥畫面（624×448，約手機螢幕高度的 1/3，角色高度約畫面的 1/8），只有在戰鬥地圖掛機或播放頭目、試煉的戰鬥時才出現；中間是所選功能的內容；最下方固定著功能方塊（圖示＋名稱：四個掛機地點，以及公會、角色、背包、試煉、設定），點一下就切換內容；點掛機地點的方塊會直接改到那裡掛機。畫面與角色大小的設定在 `src/game/config.js`。
- 戰鬥地圖的掛機畫面（`src/game/IdleScene.js`）：主角往前走（背景跟著捲動），走一段就遇到一群 2～5 隻從右邊跑來的魔物，魔物進到武器打得到的距離就停下來打，打完再繼續走（走多久、一群幾隻在檔案開頭的 `WALK_MS`、`WAVE`）。各種魔物的體型、血量（要打幾下）、跑速和跑步樣子不同（`KIND`：史萊姆跳、狼奔跑、蟲快爬、幽靈飄、人形小跑、魔像踩步）。主角用武器的三段連招打：劍、鎚打得到攻擊範圍內所有魔物，法杖的魔法球會波及旁邊、光束打一整排，弓的最後一箭貫穿。這只是表演，經驗、金幣、掉落仍由 `core` 每 5 秒結算一次。
- 場景（`src/game/scenery.js`）有草原、森林、礦坑、墓地、火山五種，依地圖順序輪流使用（第 6 張地圖會用回草原）；頭目戰用那張地圖的場景，試煉照關卡輪流。每種場景是程式畫的像素圖，加上一層會動的雲、螢火蟲、落塵、霧或火星。場景分成天空、遠景、中景、近景、地面五層（`LAYERS`），走路時越近的層捲得越快；畫的時候用 `p.layer(n)` 選要畫在哪一層，會捲動的層左右頭尾相接。
- 戰鬥結果由 `core` 先算好，Phaser 只負責把戰鬥紀錄播出來，所以「跳過」不會改變結果。
- HTML 介面和 Phaser 不直接互相呼叫，而是透過 `src/bus.js` 的事件（`state`、`tick`、`battle:start` 等，說明寫在檔案開頭）。
- 角色是 2D 骨架動畫（`src/rig/rig.js`）：把參考圖切成頭、身體、上臂、前臂、大腿、小腿等零件，掛在關節上轉動。掛機與戰鬥場景用側面，角色建立與外觀預覽用正面。動作是「時間 → 各關節角度」的函式（`ANIMS`：idle、walk、slash、jump、work、hurt），加新動作不需要重畫圖。
- 零件來自 `tools/art/ref/` 的四張參考圖（`m-front`、`m-side`、`f-front`、`f-side`，側面臉朝右）：`tools/art/extract_ref.py` 把每張圖的角色還原成固定列數的像素格（男女都是 112 列，肩膀到腳底等高），`python3 tools/art/build_rig_parts.py` 切成零件並輸出 `src/rig/parts-data.js`（需要 Pillow）。參考圖本身的方塊大約是 2×2 格，所以衣服與裝備也用 2×2 的大格上色（`rig.js` 的 `LM` 單位是大格）。髮色用色票替換。目前男女各有一種髮型；要加其他髮型，需要同樣格式的參考圖。每個性別在 `LM` 有自己的身體位置（肩、腰、膝、眼睛、頭帶），動作共用。沒穿裝備時角色就是參考圖的樣子（男生四角褲、女生背心短褲、赤腳、不拿武器）；穿了哪個部位的裝備才畫那個部位，穿上衣時會搭配長褲（女生是牛仔褲）與便鞋。
- 攻擊動作由武器的形態（`form`）決定，每種形態有一套三段連招（`rig.js` 的 `COMBOS`）：劍是下劈、反手上挑、跳斬；鎚是當頭砸、橫掃、跳起重砸（地裂、碎石）；法杖是魔法球、兩顆弧線魔法球、蓄力光束（腳下魔法陣）；弓是一箭、連射兩箭、後跳蓄力的貫穿箭；大劍（炎龍大劍）是龍炎三式（約 2.6 秒）：蓄火斜劈出巨大的火焰新月、橫掃帶出一路燒到畫面右邊的火焰波，終結技是蹲低蓄力（畫面變暗、火焰漩渦往角色收、腳下熔岩圈、背後升起光柱）後躍起斬落，一條火龍從劍尖竄上天空繞一圈再俯衝砸向敵人，命中時停頓、鏡頭拉近、火光閃爍，火柱衝到畫面頂端，衝擊波與熔岩裂縫沿地面擴散，最後下起火星雨。每套連招有三個命中時間點（`hits`），戰鬥畫面在那些時間點把這次攻擊的傷害分成 25%、30%、45% 跳出來，第三段是終結技，會震動畫面。追擊、連鎖、反擊只播第一段（`quick_*`）。之後要加技能攻擊或特殊武器，就是在 `COMBOS` 多寫一套動作，並讓武器的 `form` 指向它。特效（刀光、魔法球、箭、魔法陣、光束、爆光、衝擊波、碎石）都在 `Rig.drawFx`；跟著角色的火焰特效（火焰刀光、劍上的火舌、腳下熔岩圈）在 `src/rig/dragon.js` 的 `fireFx`；佔滿整個戰鬥畫面的大型特效（火龍、火柱、火焰波、暗場、衝擊波、熔岩裂縫、火星雨、套裝的火光輪廓）在 `src/game/stagefx.js`，用 Phaser 的粒子與加亮混色畫，時間點和 `COMBOS.greatsword` 對齊（`GS`）。`StageFx` 吃一組主題（`src/rig/sets/index.js` 的 `stageTheme`）：顏色換成那一套的特效色；大劍的終結技可以召喚火龍、骷髏或隕石；其他形態的頭目套裝武器用 `finisher()`：前幾段命中小爆光或新月斬，最後一段蓄力、大爆發，組成從尖柱、光柱、幽魂、交叉斬、箭雨、噴濺、蒸氣、落葉裡挑。主題武器在骨架裡的刀光、魔法球、箭也換成那一套的顏色（`pal.arc`）。火焰本體用一般混色保住顏色，加亮混色只用在小亮點，免得疊在白天的天空上整片變白。
- 裝備不是另外畫的圖，而是照每個零件的輪廓上色，所以換裝後所有動作都能直接用：裝備的外觀（`look`）決定款式（皮甲、板甲、法袍；武器是劍、弓、鎚、法杖），材料階級決定材質，稀有度 3 以上會發光。頭飾是另外畫的帽子（`src/rig/hats.js`），戴在頭上跟著頭轉：皮革冒險帽（稀有度越高羽毛越多）、騎士頭盔（護頰、護鼻，稀有以上有盔纓，傳說有角）、尖頂巫師帽（稀有以上有星星，史詩以上帽尖有寶珠）。戴帽子時帽簷以上的頭髮會藏起來；全罩式頭盔（炎龍角盔）整顆頭都蓋住。超出身體輪廓的裝備用「額外零件」（`rig.js` 的 `EXTRAS`）：例如炎龍鱗甲的護肩尖刺和披風（跳起來會往後飄）、炎龍爪靴的龍爪和膝刺。炎龍套裝穿 2 件以上身邊會飄火星，穿齊時角色外圍有一圈火光輪廓、背後有脈動的火光、腳下有熔岩光。頭目套裝的外觀在 `src/rig/sets/`：每一套一個檔案（色盤、頭飾、上衣、鞋子、武器、光環、終結技），共用的畫法（圓殼、折線、護肩、披風、武器畫布、光環）在 `kit.js`，`index.js` 把它們接到 `rig.js`、`hats.js`。頭冠類的頭飾（魔晶冠、古木冠、火焰冠）不壓頭髮。背包裡的裝備圖示大多仍由舊的 `src/art/chibi.js` 繪製；弓、炎龍套裝與頭目套裝改用角色身上的畫法（`rig.js` 的 `gearIcon`）。
- **炎龍套裝**（T5）：炎龍大劍、炎龍角盔、炎龍鱗甲、炎龍爪靴，只在 T5 出現（鍛造、火山掉落都可能）。穿 2 件物理攻擊、生命 +12%；穿 4 件「炎龍之怒」：攻擊附加 1 層燃燒、燃燒傷害 +10%、暴擊傷害 +30%（`data.js` 的 `SETS`）。外觀與特效在 `src/rig/dragon.js`，在 `/tools/rig.html` 選「炎龍套裝」可以看。

## 加新裝備

完整的製作流程（要問使用者什麼、改哪些檔案、外觀與特效的原則、檢查用的腳本、交付步驟）寫在 `.claude/skills/gear-design/SKILL.md`，請 Claude 做裝備時會照著做。設定頁有「取得全部裝備」「刪除全部裝備」的測試按鈕（新裝備會自動包含在內；款式比背包格子多，取得全部時背包會超過上限，要賣掉一些才能繼續鍛造），`/tools/rig.html` 的服裝選單也會自動列出每一套。

每一款裝備是 `src/core/gear.js` 裡的一列：`id`（存檔用，加了就不要改）、部位、名稱、外觀（`look`）、武器的形態（`form`）、基本數值，鍛造配方（`cost`），以及選填的 `tier`（只在某個材料階級出現）、`set`（屬於哪一套，套裝效果寫在 `data.js` 的 `SETS`）。裝備物件只存 `def`（樣式 id）、階級、稀有度和抽到的數值，名稱、外觀、效果說明在讀檔時從樣式表重建，所以改名稱或說明，舊裝備也會跟著更新。

- **沿用現有外觀**（例如再加一把劍、一件板甲）：只要在 `gear.js` 加一列，鍛造、掉落、背包、鍛造室的款式選單都會自動出現。
- **新的外觀**：除了加一列，還要畫出來。沒畫的外觀會先用同部位的預設畫法，不會壞掉。
  - 遊戲中的角色：武器在 `src/rig/rig.js` 的 `WEAPON_LOOKS`，上衣在 `BODY_LOOKS`，鞋子在 `FEET_LOOKS`，帽子在 `src/rig/hats.js` 的 `STYLES`；護肩、披風這類超出身體的部分加在 `EXTRAS`。整套主題裝備放在 `src/rig/sets/<套裝>.js`（照現有的檔案寫一個，加進 `index.js` 的 `LIST`；外觀代號是「套裝代號＋weapon／helm／body／feet」，畫法、背包圖示、光環、戰鬥畫面特效都會自動接上）。
  - 背包圖示：把外觀加進 `rig.js` 的 `RIG_ICON_LOOKS`，就會用角色身上的畫法；飾品在 `src/art/icons.js`，其他舊外觀在 `src/art/chibi.js`。
- **新的武器形態**（攻擊方式不同）：在 `src/core/data.js` 的 `FORMS` 加一種（決定職業和職業機制），在 `rig.js` 的 `COMBOS` 寫一套連招。

存檔有版本號（`v`）。格式改變時在 `src/core/save.js` 加一段轉換，像 `fromV1` 把舊的「流派」存檔轉成現在的格式。
