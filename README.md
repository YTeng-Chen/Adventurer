# 冒險者 ADVENTURE（暫定名稱）

像素風的放置養成 RPG 原型：平日掛機養成，假日挑戰神之試煉、親手搭配祝福。

## 開始開發

需要 Node.js 20 以上。

```bash
npm install
```

```bash
npm run dev
```

開啟終端機顯示的網址就能玩。其他指令：

- `npm run build`：打包到 `dist/`，整個資料夾放到任何網頁空間都能開。
- `npm run preview`：在本機預覽打包結果。
- `npm test`：執行遊戲規則的測試。
- 開發時打開 `/tools/sprites.html`：一次看男女角色、各種裝備外觀、稀有度、材料階級的裝備像素圖，以及所有背包圖示。
- 開發時打開 `/tools/hairstyles.html`：早期的髮型挑選頁（舊的手繪 Q 版，遊戲已不使用）。
- 開發時打開 `/tools/rig.html`：骨架動畫預覽（`src/rig/`）。可切換正面與側面、性別、髮色、服裝、稀有度、材料階級，播放待機、走路、四種武器的三段連招、受擊。
- 開發時打開 `/tools/model3d.html`：3D 像素風人物設計稿（Three.js，`src/three/`）。已放棄這個方向，留作紀錄，遊戲沒有使用。

第一次進遊戲會先建立角色（性別與髮色），之後可以在角色面板按「更換外觀」修改。進度存在瀏覽器裡。「設定」裡的「快轉 1 小時」是測試用的，可以馬上看到離線收穫。

## 怎麼玩

- **掛機地點**：鍛鍊室、戰鬥地圖、鍛造室、市集、公會，同時只能選一處。每 5 秒結算一次，關掉網頁也會繼續（最多 12 小時）。
- **裝備與職業**：每張地圖掉一種材料（每個階級一種），鍛造時用哪一階的材料就做出哪一階的裝備，可以指定部位和款式。職業由武器決定：劍是劍士、弓是弓手（連鎖），鎚是守衛（反擊），法杖是術士（燃燒）；防具和飾品不影響職業，飾品專門出詞條。裝備不限階級，誰都能穿。史詩、傳說裝備有會改變戰鬥行為的特殊效果。角色外觀會隨裝備改變。
- **冒險者階級**：新手、初級、中級、高級、資深、傳奇冒險者，看冒險者聲望（在公會掛機、完成公會任務會增加），在 `data.js` 的 `RANKS`。要去下一張戰鬥地圖（和狩獵它的頭目）有兩個條件：冒險者階級要夠，也要打倒前一張地圖的頭目。綠風草原新手就能去，幽暗森林要初級、鐵鏽礦坑中級、亡者墓穴高級、熔岩火山資深（`AREAS` 的 `rank`）。越高級的地圖掉越高階的材料，才做得出高階裝備。階級越高，公會委託的收入也越多。
- **魔物狩獵**：用狩獵券挑戰各地圖的頭目（要能去那張地圖），打倒後下一張地圖就少一個條件；掉落那張地圖階級的材料和稀有以上的裝備；首次擊敗金幣 ×3。
- **神之試煉**：每週一重置，每過 3 關從三個祝福中選一個（一般、稀世、史詩、神之四級）。

## 架構

分成三層，彼此只透過明確的介面溝通：

| 資料夾 | 負責 | 用到 |
| --- | --- | --- |
| `src/core/` | 遊戲規則：數值、戰鬥、掛機結算、鍛造、試煉、存檔。純運算，不碰畫面 | 無 |
| `src/ui/` | 文字多的畫面：HUD、角色數值、掛機地點、背包、任務、祝福選擇 | HTML / CSS |
| `src/game/` | 戰鬥畫面：戰鬥地圖的掛機場景、戰鬥播放、傷害數字、裝備閃光 | Phaser 4 |

- 版面以手機直式為主（單欄，桌機上置中）：最上面是狀態列；接著是戰鬥畫面（624×448，約手機螢幕高度的 1/3，角色高度約畫面的 1/8），只有在戰鬥地圖掛機或播放狩獵、試煉的戰鬥時才出現；中間是所選功能的內容；最下方固定著功能方塊（圖示＋名稱：五個掛機地點，以及角色、背包、狩獵、試煉、設定），點一下就切換內容；點掛機地點的方塊會直接改到那裡掛機。畫面與角色大小的設定在 `src/game/config.js`。
- 戰鬥地圖的掛機畫面（`src/game/IdleScene.js`）：每秒從右邊跑出一隻魔物，各種魔物的體型、血量（要打幾下）、跑速和跑步樣子不同（`KIND`：史萊姆跳、狼奔跑、蟲快爬、幽靈飄、人形小跑、魔像踩步）。主角原地用武器的三段連招打：劍、鎚打得到攻擊範圍內所有魔物，法杖的魔法球會波及旁邊、光束打一整排，弓的最後一箭貫穿。這只是表演，經驗、金幣、掉落仍由 `core` 每 5 秒結算一次。
- 場景（`src/game/scenery.js`）有草原、森林、礦坑、墓地、火山五種，依地圖順序輪流使用（第 6 張地圖會用回草原）；狩獵頭目用那張地圖的場景，試煉照關卡輪流。每種場景是程式畫的像素圖，加上一層會動的雲、螢火蟲、落塵、霧或火星。
- 戰鬥結果由 `core` 先算好，Phaser 只負責把戰鬥紀錄播出來，所以「跳過」不會改變結果。
- HTML 介面和 Phaser 不直接互相呼叫，而是透過 `src/bus.js` 的事件（`state`、`tick`、`battle:start` 等，說明寫在檔案開頭）。
- 角色是 2D 骨架動畫（`src/rig/rig.js`）：把參考圖切成頭、身體、上臂、前臂、大腿、小腿等零件，掛在關節上轉動。掛機與戰鬥場景用側面，角色建立與外觀預覽用正面。動作是「時間 → 各關節角度」的函式（`ANIMS`：idle、walk、slash、jump、work、hurt），加新動作不需要重畫圖。
- 零件來自 `tools/art/ref/` 的四張參考圖（`m-front`、`m-side`、`f-front`、`f-side`，側面臉朝右）：`tools/art/extract_ref.py` 把每張圖的角色還原成固定列數的像素格（男女都是 112 列，肩膀到腳底等高），`python3 tools/art/build_rig_parts.py` 切成零件並輸出 `src/rig/parts-data.js`（需要 Pillow）。參考圖本身的方塊大約是 2×2 格，所以衣服與裝備也用 2×2 的大格上色（`rig.js` 的 `LM` 單位是大格）。髮色用色票替換。目前男女各有一種髮型；要加其他髮型，需要同樣格式的參考圖。每個性別在 `LM` 有自己的身體位置（肩、腰、膝、眼睛、頭帶），動作共用。沒穿裝備時角色就是參考圖的樣子（男生四角褲、女生背心短褲、赤腳、不拿武器）；穿了哪個部位的裝備才畫那個部位，穿上衣時會搭配長褲（女生是牛仔褲）與便鞋。
- 攻擊動作由武器的形態（`form`）決定，每種形態有一套三段連招（`rig.js` 的 `COMBOS`）：劍是下劈、反手上挑、跳斬；鎚是當頭砸、橫掃、跳起重砸（地裂、碎石）；法杖是魔法球、兩顆弧線魔法球、蓄力光束（腳下魔法陣）；弓是一箭、連射兩箭、後跳蓄力的貫穿箭。每套連招有三個命中時間點（`hits`），戰鬥畫面在那些時間點把這次攻擊的傷害分成 25%、30%、45% 跳出來，第三段是終結技，會震動畫面。追擊、連鎖、反擊只播第一段（`quick_*`）。之後要加技能攻擊或特殊武器，就是在 `COMBOS` 多寫一套動作，並讓武器的 `form` 指向它。特效（刀光、魔法球、箭、魔法陣、光束、爆光、衝擊波、碎石）都在 `Rig.drawFx`。
- 裝備不是另外畫的圖，而是照每個零件的輪廓上色，所以換裝後所有動作都能直接用：裝備的外觀（`look`）決定款式（皮甲、板甲、法袍；武器是劍、弓、鎚、法杖），材料階級決定材質，稀有度 3 以上會發光。頭飾是另外畫的帽子（`src/rig/hats.js`），戴在頭上跟著頭轉：皮革冒險帽（稀有度越高羽毛越多）、騎士頭盔（護頰、護鼻，稀有以上有盔纓，傳說有角）、尖頂巫師帽（稀有以上有星星，史詩以上帽尖有寶珠）。戴帽子時帽簷以上的頭髮會藏起來。背包裡的裝備圖示仍由舊的 `src/art/chibi.js` 繪製。

## 加新裝備

每一款裝備是 `src/core/gear.js` 裡的一列：`id`（存檔用，加了就不要改）、部位、名稱、外觀（`look`）、武器的形態（`form`）、基本數值。裝備物件只存 `def`（樣式 id）、階級、稀有度和抽到的數值，名稱、外觀、效果說明在讀檔時從樣式表重建，所以改名稱或說明，舊裝備也會跟著更新。

- **沿用現有外觀**（例如再加一把劍、一件板甲）：只要在 `gear.js` 加一列，鍛造、掉落、背包、鍛造室的款式選單都會自動出現。
- **新的外觀**：除了加一列，還要畫出來。沒畫的外觀會先用同部位的預設畫法，不會壞掉。
  - 遊戲中的角色：武器在 `src/rig/rig.js` 的 `WEAPON_LOOKS`，上衣在 `BODY_LOOKS`，鞋子在 `FEET_LOOKS`，帽子在 `src/rig/hats.js` 的 `STYLES`。
  - 背包圖示：飾品在 `src/art/icons.js`，其他部位在舊的 `src/art/chibi.js`（弓目前還沒有自己的圖示，用劍的圖）。
- **新的武器形態**（攻擊方式不同）：在 `src/core/data.js` 的 `FORMS` 加一種（決定職業和職業機制），在 `rig.js` 的 `COMBOS` 寫一套連招。

存檔有版本號（`v`）。格式改變時在 `src/core/save.js` 加一段轉換，像 `fromV1` 把舊的「流派」存檔轉成現在的格式。

```
index.html          頁面骨架
src/main.js         進入點
src/bus.js          介面與 Phaser 之間的事件
src/style.css       樣式
src/core/           遊戲規則（data.js 是平衡數值，gear.js 是裝備樣式表）
src/ui/app.js       HTML 介面
src/ui/nav-icons.js 功能方塊的像素圖示
src/ui/sprites.js   像素圖入口（魔物資料）
src/art/            裝備圖示的像素繪製（chibi.js 是舊的手繪角色，只剩圖示在用）
src/rig/            骨架動畫角色：rig.js（繪製與動作）、parts-data.js（零件）
src/game/           Phaser：IdleScene、BattleScene、textures
tests/              遊戲規則測試
tools/sprites.html  像素圖預覽（開發用）
tools/rig.html      骨架動畫預覽（開發用）
tools/art/          參考圖與零件產生工具（Python）
```
