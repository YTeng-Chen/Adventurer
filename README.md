# 冒險者 ADVENTURE（暫定名稱）

像素風的放置養成 RPG 原型：平日掛機養成，假日挑戰神之試煉、親手搭配祝福。

## 怎麼玩

用瀏覽器直接打開 `index.html` 就能玩，不需要安裝任何東西。進度存在瀏覽器裡。

- **掛機地點**：鍛鍊室、戰鬥地圖、鍛造室、市集、公會，同時只能選一處。每 5 秒結算一次，關掉網頁也會繼續（最多 12 小時）。
- **裝備與職業**：鍛造時用哪個流派的材料，就做出哪個流派的裝備。武器、頭飾、上衣、鞋子中有 3 件同流派就是專精職業，2+2 會變成混合職業；飾品不影響職業，專門出詞條。史詩、傳說裝備有會改變戰鬥行為的特殊效果。角色外觀會隨裝備改變。
- **魔物狩獵**：用狩獵券挑戰各地圖的頭目，首次擊敗解鎖下一張地圖。
- **神之試煉**：每週一重置，每過 3 關從三個祝福中選一個（一般、稀世、史詩、神之四級）。

頁面底部的「快轉 1 小時」是測試用的，可以馬上看到離線收穫。

## 程式結構

```
index.html        頁面
css/style.css     樣式
js/core/          遊戲規則（純運算，不碰畫面）
  data.js         所有平衡數值與資料表
  stats.js        角色數值、職業判定
  items.js        裝備產生
  combat.js       戰鬥模擬
  world.js        掛機結算、鍛造、市集、公會、狩獵
  trial.js        神之試煉
  save.js         存檔
js/ui/            畫面
  sprites.js      像素圖
  app.js          介面
tests/            核心邏輯測試
```

## 測試

```bash
npm test
```
